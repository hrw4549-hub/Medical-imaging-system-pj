# 超声图像增强与降噪实验项目

本项目完成题目截图中的两项实验。指标和图像均由 `data1.zip` 中的四张原图实际计算。题目规定的四个原始图像文件名予以保留，便于对照作业要求；其余目录和主要文件均采用中文名称。

## 先看报告

打开 `超声图像增强与降噪实验报告.docx`，正文和表格可以在 Word 中修改，图表以图片形式嵌入。

## 实验内容

1. 对高、低端设备超声图像分析灰度分布；完成全局直方图均衡化、双向直方图规定化和 CLAHE，比较结果、直方图、累计分布及 CLAHE 参数敏感性。
2. 为干净超声图添加标准差为 15 的高斯噪声；分别用高斯滤波和自行训练的残差 CNN 降噪，并在独立空间测试区比较 PSNR、SSIM、MAE。
3. 将相同降噪方法应用于真实含噪超声图。真实图没有配对干净参考，因此只进行视觉和描述性分析，不报告无依据的 PSNR 或 SSIM。

## 运行环境

推荐 Python 3.10 或更高版本，并在独立环境中安装 `运行依赖.txt` 列出的库。

```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r 运行依赖.txt
python 运行实验.py
python 验证结果.py
```

默认直接加载 `模型/残差卷积网络权重.pt`。重新训练时执行：

```bash
python 运行实验.py --retrain --steps 1800 --seed 42
```

强制 CPU 推理时添加 `--device cpu`。CUDA 加速需要匹配的显卡驱动与 PyTorch。Windows 可双击 `运行实验.bat`；它为本次进程设置 OpenMP 兼容变量，不修改全局配置。实验脚本重新生成结果和报告内容后，运行 `python 生成中文报告.py` 即可更新可编辑 DOCX。复现会重建 `实验结果` 中的图表、指标、Markdown 和 HTML 临时文件。

## 结果与评估说明

- 残差 CNN 是自行编写和训练的 8 层网络，共 56,097 个参数；不是原版 DnCNN，也不依赖预训练模型。
- 600×600 干净图按空间块划分训练、验证和测试。测试区留出 12 像素边界，避免卷积与 SSIM 上下文跨入训练区域。训练和测试仍来自同一张图，不能据此声称跨患者泛化。
- 指标还单独计算测试区内的超声扇形，降低黑色背景对分数的影响。全图指标包含训练区，只作补充。
- 高斯噪声先叠加再截断到 0～255；黑色背景处截断会造成正偏，指标比较保留这一影响。
- `Figure2_clean` 和 `Figure2_noisy` 尺寸、内容不同，不是配准的真值对。真实含噪图只作定性和描述性比较。
- 所有原图名称保持与题目一致，运行前后均不覆盖原文件。输入校验和运行库版本保存在 `实验结果/实验记录.json`。
