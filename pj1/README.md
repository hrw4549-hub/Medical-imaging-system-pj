# PJ1 超声图像增强与降噪

本项目完成超声图像灰度分布分析、直方图均衡化、直方图规定化、CLAHE，以及传统和深度学习降噪比较。实验报告为可编辑的 Word 文档。

## 文件说明

- `超声图像增强与降噪实验报告.docx`：完整实验报告，含处理图、统计结果和分析。
- `运行实验.py`：增强、加噪、模型训练或推理、指标计算及结果图生成。
- `验证结果.py`：校验输入图像、重算结果指标并检查模型输出。
- `生成中文报告.py`：根据实验结果生成可编辑 DOCX 报告。
- `运行依赖.txt`：Python 依赖。
- `运行实验.bat`：Windows 启动脚本。
- `原始数据/`：题目提供的四幅图像，保留原始文件名。
- `模型/残差卷积网络权重.pt`：本项目自行训练的残差 CNN 权重及训练记录。
- `实验结果/`：中文命名的处理图、对比图、评价掩膜、CSV 指标和 JSON 实验记录。

## 运行方法

需要 Python 3.10 或更高版本。建议创建独立虚拟环境，并在项目目录打开终端：

```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r 运行依赖.txt
python 运行实验.py
python 验证结果.py
```

默认使用随项目提供的模型权重，不需要重新训练。重新训练可运行：

```bash
python 运行实验.py --retrain --steps 1800 --seed 42
```

强制使用 CPU 推理可添加 `--device cpu`。GPU 训练需要正确安装与显卡驱动匹配的 CUDA 版 PyTorch。

## 实验内容

1. 分析高、低端设备超声图像的灰度直方图，并比较全局直方图均衡化、双向直方图规定化与 CLAHE 的效果。
2. 对 `Figure2_clean.png` 添加标准差为 15 的高斯噪声，采用高斯滤波和自行训练的 8 层残差 CNN 进行降噪，在留出的空间测试区计算 PSNR、SSIM 和 MAE。
3. 将相同降噪方法应用于 `Figure2_noisy.png`，通过结果图和 ROI 描述统计观察其在真实含噪图上的表现。

## 结果摘要

在固定随机种子和独立空间测试区内，人工加噪基线 PSNR 为 26.726 dB，高斯滤波为 31.115 dB，残差 CNN 为 38.268 dB。测试区内超声扇形的 PSNR 分别为 26.361 dB、31.894 dB 和 36.888 dB。真实含噪图没有配对干净参考，因此使用图像对比和描述性统计展示处理变化，不计算配对 PSNR 或 SSIM。

本实验训练和测试区域取自同一幅干净超声图，结果用于展示本次实验流程及其设定下的表现。
